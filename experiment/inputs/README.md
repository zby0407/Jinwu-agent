# 输入目录

将需要实验读取的本地数据或符合 worker 接口的现有脚本复制到本目录，再通过 `/automatic-experiment` 引用相对路径。

`inputs/example_mean.csv` 只是安装与执行链路演示数据：四条记录的 `value` 总体均值为 `2.5`，`group` 列特意保留但不会被“计算全部 value 均值”的示例任务使用。它不是默认数据集、固定实验模板或科研结论来源。真实任务应提供自己的输入并明确分析目标。

真实任务可以提供零到多份上游反馈和零到多个处理后产物，不要求固定文件数量或固定 Agent 来源。最常见的交接是一份规划反馈、一份数据/特征反馈和一张处理后表格；`inputs/upstream_handoff_demo/` 正是用这组三件套构造的主测试夹具。目录内所有内容均为合成测试材料，不能当作真实太阳观测证据。

自动实验 Agent 不读取本目录之外的普通项目文件，也拒绝符号链接、硬链接、隐藏文件、秘密样式文件名、测试、评估和私有目录。高级请求 JSON 也必须位于本目录或已完成运行的 `public/` 目录。
