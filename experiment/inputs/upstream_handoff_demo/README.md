# 上游 Agent 接力演示包

本目录用于模拟真实科研流程中最常见的一次“三件套”交接：

- `research_plan_feedback.md`：模拟研究规划 Agent 已完成的范围、路线和停止条件反馈。
- `data_feature_feedback.json`：模拟数据与特征 Agent 对已处理数据、字段、质量标记和能力边界的反馈。
- `polar_overlap_features.csv`：供自动实验 Agent 真实执行的处理后特征表。

真实任务不要求固定是三份材料，可以增减反馈、表格、脚本或其他产物。这里选择三件套，是为了检验自动实验 Agent 能否为不同材料建立研究角色，判断当前数据支持和暂不支持的问题，自主选择分析、对照和稳健性检查，并把每项判据追溯到真实测量或端点。

这是一套合成测试夹具，不是真实太阳观测，也不能支持第 26 太阳活动周预测或任何正式科学结论。
