# JW 科研结果发布质检

这项技能面向 JW 太阳周期科研闭环的最终产物，不采用数学建模竞赛的格式假设。它只在研究内容已经生成后使用，负责确认导出结果没有改变科学含义，也没有把内部过程泄露给读者。

## 证据与语义检查

- 检查图表、表格和正文是否来自当前任务绑定的工件与回执；旧运行、合成数据和模型自述不能作为替代。
- 核对观测量、代理量、派生特征、预测值和机制解释的标签，尤其不能把极区孔径场写成轴向偶极矩，也不能把 F10.7 写成内部磁场。
- 核对周期编号、时间方向、训练/测试边界、样本量、基线、误差指标和不确定性；负结果、区间跨零和证据不足必须保留。
- 检查缺失数据、测量阶段差异和 `blocked`/`revise`/`accept_with_limits` 状态是否在读者可见结论中如实呈现。

## 导出与视觉检查

对实际导出的 PDF、HTML、DOCX、PNG 或 SVG 逐页/逐图检查：公式没有变成原始源码，文字和刻度在实际插入尺寸下可读，图例不遮挡数据，颜色和线型含义稳定，标题和图注说明“显示了什么”以及“证据支持到哪里”。不得在读者可见内容中放本地路径、脚本名、供应商、内部阶段名或审计实现细节。

## 交付边界

静态检查、真实渲染和科学结论分别记录。任何关键字段丢失、渲染改变含义、视觉不可读或来源无法追溯时，返回 `revise` 或 `blocked`，不要通过删去限制、改写数字或重新包装旧结果来通过质检。
