# Adobe Finish Playbook

Use this guide when the figure already exists conceptually and the task is to polish, compose, or annotate it for a contest paper.

## Choose the App Explicitly

- Use Illustrator for vector cleanup, alignment, typography, icons, and panel composition.
- Use Photoshop for raster cleanup, bitmap annotations, resolution repair, and image compositing.

Illustrator is the default Adobe route for contest-paper figures because it preserves vector structure and leaves behind an `.ai` source file.

## What to Record

Always specify:

- artboard size
- layer plan
- imported source files
- alignment rules
- font family and size
- stroke widths
- callout or annotation style
- export format
- native source filename

## Typical Instruction Pattern

1. Create the artboard at the final paper-friendly size.
2. Import the chart or diagram sources.
3. Lock the background or base layers.
4. Add annotation layers and title layers separately.
5. Align panels and enforce equal margins.
6. Normalize stroke widths and font sizes.
7. Export the final version for the paper.

## Hard Rule

If Illustrator or Photoshop is only being named as a vague "polish later" tool, the plan is incomplete.

State what will be imported, what will be adjusted, and what the exported result should look like.
