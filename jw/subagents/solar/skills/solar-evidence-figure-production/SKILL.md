# JW 太阳周期证据图生产

这项技能服务于 JW 的太阳周期科研闭环，不沿用数学建模竞赛的制图流程。每一幅图都必须回答一个明确的研究问题：描述观测、比较预测、检验机制、展示不确定性，或支撑一个发布决策。装饰性图形不进入科研结论。

## 证据先行

1. 先登记图的目的、输入工件、观测量定义、时间范围、单位、聚合方式和允许的结论强度。
2. 只使用当前任务绑定且有回执的 SILSO、F10.7、极区磁场或实验输出；路径、文件名和模型自述不能替代数据回执。
3. 明确区分观测量、代理量、派生特征、预测值和机制解释。极区孔径场不能标成轴向偶极矩，F10.7 不能标成内部磁场。
4. 图中显示缺失值、测量阶段变化、基线、置信区间或 bootstrap 区间；没有估计就不要绘制“误差带”。

## 太阳周期专用检查

- 横轴使用 ISO 日期或活动周期编号，并在图注说明周期边界来源。
- 周期级比较标明样本数、训练/测试时间方向和预测起点，禁止把未来观测泄漏到特征中。
- 负相关、零相关和区间跨零都保留原样；图形不能暗示尚未检验的因果方向。
- MWO 代理时代、WSO 磁力计时代和其他仪器阶段分层显示，不能把不同观测制度拼成一个无断点序列。
- 对周期 1–24 回测或周期 26 预测，图注同时给出基线、误差指标和失败/缺失周期。

## 生产与复核

优先选择可复现的脚本或项目批准的矢量路线，并保留生成图所需的数据表、代码和版本信息。绘图代码与数值计算分开；脚本输出是候选图，不能自动成为发布图。

发布前逐图检查：

1. 语义：轴、单位、图例、颜色和标记与数据字段一致；没有重复计数或隐藏筛选。
2. 统计：区间、基线和样本量可追溯；图上结论不超过 evidence review 的结论上限。
3. 视觉：实际插入宽度下文字可读，刻度和图例不遮挡数据，色盲安全且黑白打印仍能区分关键类别。
4. 复现：保存最终 PNG/SVG 及其源表，并在运行台账记录输入回执、输出路径和检查结果。

若任一关键输入缺失、观测语义不明确、区间无法解释或视觉检查失败，返回 `revise`/`blocked`，不要用合成数据、旧运行结果或手工美化绕过门槛。

## 读者可见文字

标题和图注使用自然的科研语言，说明“显示了什么”和“证据支持到哪里”。不要在图中放本地路径、脚本名、内部阶段名、模型供应商或审计哈希。
