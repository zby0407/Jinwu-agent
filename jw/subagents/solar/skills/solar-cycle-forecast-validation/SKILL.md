# 太阳活动周预测验证

## 核心原则

预测能力只由“在当时可获得的信息预测未来”的重复实验支持。描述性拟合、全样本相关和事后修订数据不能替代 out-of-sample 证据。

## 执行合同

1. 冻结目标定义、forecast issue date、可用数据版本和候选特征。为每个测试周期建立 as-of 快照；无法证明当时可见的特征不得进入该折。
2. 使用 expanding-window 或 rolling-origin 外层回测；标准化、缺失处理、特征筛选与调参仅在训练折完成。历史过短时限制模型自由度和搜索空间。
3. 至少比较一个可解释基线，如上一周期、历史均值或预先登记的物理 precursor。主模型必须在相同折、相同目标和相同信息集上比较。
4. 同时报告逐周期误差、MAE/RMSE、相对基线差异、预测区间覆盖和模型排名不确定性。重采样方案必须说明小样本与周期依赖限制；不能用窄区间制造确定感。
5. 保留困难周期和失败折。将强弱周期、数据质量、仪器或定义变更作为预先说明的 regime 诊断，不得据此删除不利结果。

## 判定输出

输出依次包含：预测合同、as-of 数据矩阵、回测折、基线对照、稳定性诊断、可部署结论。结论只能是 `supported`、`competitive_with_baseline`、`unstable` 或 `insufficient_evidence`，并说明最影响下一次预测的证据缺口。

## 常见错误

| 错误 | 修正 |
|---|---|
| 用最终修订数据重建旧预测 | 保存并绑定逐预测时点快照 |
| 只公布最优 RMSE | 公布全部折和排名不确定性 |
| 删除异常或困难周期 | 保留主分析，仅另做敏感性诊断 |
| 把 precursor 相关写成因果 | 将预测技能与机制解释分开审查 |
