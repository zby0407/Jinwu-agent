# 太阳活动周预测验证

## 核心原则

预测能力只由“使用预测时点当时可获得的信息预测未来”的重复实验支持。描述性拟合、全样本相关、最终修订数据和一次有利点估计不能替代样本外证据。

## 预测合同

开始计算前固定目标、forecast origin、issue date、信息截止、数据版本、候选模型、基线和判定规则。为每个测试周期建立 as-of 信息集；无法证明当时可见的特征不得进入该折。暂定标签、最终标签和后续修订分别标记，暂定周期不得回填历史技能门。

## 时间顺序验证

1. 使用 expanding-window 或 rolling-origin 外层回测。标准化、缺失处理、特征选择、调参和模型选择只能在训练折内完成。
2. 历史周期过少时限制自由度和候选数量；先比较上一周期、训练均值等透明基线，再考虑复杂模型。
3. 所有候选必须使用相同测试折、目标和信息集。困难周期、失败折、负改善和缺失输入保留在主结果中。
4. 同时报告逐周期预测、MAE/RMSE、相对基线改善、预测区间覆盖和模型排名不确定性。bootstrap 不能把少数周期变成大量独立样本。
5. MWO 代理与 WSO 磁强计等测量制度分别报告；制度差异是测量敏感性，不能写成太阳物理 regime。

## H2 专用约束

H2 的历史技能门保留两半球均值主模型。平方根、目标峰值离散度加权和较弱半球模型只作预先固定的敏感性检验，不根据同一测试集事后晋升。SC25 等暂定检查必须标记 `excluded_from_skill_gate=true`。

## 判定

沿用 JW 合同输出 `skill_supported`、`mixed_evidence`、`tested_no_skill`、`blocked_by_data` 或 `execution_failed`。每个 verdict 必须列出最主要的误差、区间、失败折和下一项可解除不确定性的证据。

## 常见错误

| 错误 | 修正 |
|---|---|
| 用最终修订数据重建旧预测 | 保存并绑定逐预测时点快照 |
| 只公布最优模型的平均误差 | 公布全部折、基线和排名不确定性 |
| 删除异常或困难周期 | 保留主分析，另做预先说明的敏感性诊断 |
| 把前兆相关写成因果 | 将预测技能与机制证据分开审查 |
