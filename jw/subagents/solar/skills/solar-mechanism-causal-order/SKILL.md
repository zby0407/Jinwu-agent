# 太阳机制与因果顺序审查

## 核心原则

先建立物理时间顺序和可观测量映射，再评价统计关系。相关可以支持预测或机制相容性，不能单独证明因果机制。

## 因果顺序

对 Babcock–Leighton 类解释，至少核对：

`cycle n 活动区磁通与倾角` → `表面磁通输运和跨赤道抵消` → `n 与 n+1 之间极小期的极区场或轴向偶极矩` → `内部输运、储存与剪切` → `cycle n+1 环向场与活动区涌现` → `cycle n+1 振幅`。

每条箭头必须说明方向、时间窗，以及中介对应直接观测、声明过的代理量还是受约束模型。不得把目标周期已经发生的信息放回 forecast origin 之前。

## 可观测量语义

- 轴向偶极矩是带符号的全局低阶量；南北极区场绝对值平均是无符号强度。二者不能互换后沿用同一机制解释。
- 说明仪器、空间采样、平滑、极小期窗口和代理记录。代理与直接观测的切换必须做分时期敏感性。
- 年代、测量制度和太阳状态可能分别对应测量漂移、共同驱动或 effect modifier，必须作为竞争解释区分。

## 证据阶梯

1. **时间先行：** 前兆在 issue date 前形成。
2. **预测增量：** rolling-origin 中优于同信息集基线。
3. **机制中介：** 磁通输运、极性演化或预定中介量方向一致。
4. **替代解释：** 比较共同驱动、测量漂移、非线性、regime 和适用的负对照。
5. **机制判定：** 只有多层独立证据一致才提高机制支持；单一显著相关最多标为 `mechanism_compatible`。

## 输出合同

输出因果图、时点表、观测量字典、可区分预测、竞争机制和证据等级。允许 verdict 为 `predictive_only`、`mechanism_compatible`、`mechanism_supported_with_limits` 或 `insufficient_evidence`。
