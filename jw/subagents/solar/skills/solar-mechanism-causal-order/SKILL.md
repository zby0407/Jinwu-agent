# 太阳机制与因果顺序审查

## 核心原则

先画出物理时间顺序和可观测量映射，再评价统计关系。相关可以支持预测或机制相容性，不能单独证明因果机制。

## 因果顺序

对 Babcock-Leighton 类解释，至少核对：

`cycle n 活动区磁通/倾角` → `表面磁通输运与跨赤道抵消` → `n 与 n+1 之间极小期的极区场/轴向二极矩` → `内部输运、储存与剪切` → `cycle n+1 环向场和活动区涌现` → `cycle n+1 振幅`。

每条箭头必须有方向、时间窗，以及中介的直接观测、已声明代理或受约束模型证据。还要列出竞争解释。不得把 cycle n 的峰值后变量误当作更早可用前兆，也不得用 cycle n+1 已发生的信息解释同一周期预测。

## 可观测量语义

- 轴向二极矩是带符号的全局低阶量；南北极场绝对值平均是无符号强度。两者可服务不同问题，不能互换后沿用同一机制解释。
- 说明仪器、代理记录、空间采样、平滑与极小期窗口。代理量切换必须单独做时期敏感性，不以拼接后的长序列自动增加因果强度。
- 周期状态或年代相关的太阳物理过程可成为共同驱动或 effect modifier，不是默认中介。观测制度属于测量过程，应通过分时期和测量敏感性处理，不能写成太阳物理原因。

## 证据阶梯

1. **时间先行**：前兆在 forecast issue date 前形成。
2. **预测增量**：rolling-origin 中优于同信息集基线。
3. **机制中介**：磁通输运、极性演化或相关中介量与预定方向一致。
4. **排除替代解释**：比较共同驱动、测量漂移、非线性和 regime 模型；加入 placebo lag 或不应响应的负对照。
5. **机制判定**：只有多层独立证据一致时才提高机制支持；单一相关显著最多记为 `mechanism_compatible`。

## 输出合同

输出因果图、时点表、观测量字典、可区分预测、竞争机制和证据等级。允许结论为 `predictive_only`、`mechanism_compatible`、`mechanism_supported_with_limits` 或 `insufficient_evidence`。

## 常见错误

| 错误 | 修正 |
|---|---|
| 把绝对极区场写成带符号偶极矩 | 分开变量、单位和物理含义 |
| 显著相关即宣称发电机机制 | 逐级检查中介与替代解释 |
| 混合代理与直接观测后忽略年代 | 做分时期与测量制度敏感性 |
