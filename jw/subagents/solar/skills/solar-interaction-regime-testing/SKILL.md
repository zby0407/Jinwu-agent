# 太阳周期交互与 Regime 检验

## 核心原则

物理调制不等同于固定符号的线性交互。正交互与负交互都证据不足时，保留加性模型，并把 H3 改写为可证伪的“关系是否随状态改变”，不能强迫方向。

## 可检验假设

先定义响应 (Y)、前兆 (P)、候选调制量 (L) 和预测时点。核心比较为：

- **M0 加性模型**：(Y \sim P + L)。
- **M1 线性交互**：(Y \sim P + L + P\times L)，不预设正负；报告交互效应区间与预测增量。
- **M2 一个替代分支**：仅在外部物理依据预先给出阈值、非线性形式或 regime 定义，且每个状态有足够独立周期时使用。不得从同一小样本同时搜索切点、函数和结论。

M1/M2 都不稳定时，H3 状态为 `inconclusive_low_power` 或 `no_detectable_modification`，不是被迫转向另一符号。

## 识别性检查

1. 在训练折内中心化连续变量；检查主效应、交互项、年代和测量制度是否近共线。
2. 约十个周期对时，模型自由度必须低于可识别范围；不能同时估计潜变量、多个切点和多种交互。代理/直接观测差异优先做分时期敏感性，而非堆叠参数。
3. 对未来预测使用 chronological rolling-origin；leave-one-cycle-out 只作影响诊断，不冒充真实历史预测。
4. 置换或重采样只有在 exchangeability 与时间依赖假设成立时使用，并披露低功效和区间宽度。

## 证据输出

同时报告 M0/M1/M2 的逐周期结果、交互区间、符号跨折稳定性、相对加性模型的 out-of-sample 增量、测量制度敏感性和 identifiability 诊断。物理解释只对应预注册状态变量，不把仪器年代写成太阳 regime。

## 判定

- `signed_interaction_supported`：方向、区间和样本外增量一致。
- `regime_modification_supported`：预注册 M2 稳定优于 M0，且不是测量制度产物。
- `no_detectable_modification`：有足够辨别力但 M1/M2 无实质增量。
- `inconclusive_low_power`：样本或识别性不足；保留零假设、正负方向和后续数据需求。

## 常见错误

| 错误 | 修正 |
|---|---|
| 区间跨零后改选相反符号 | 保留证据不足 |
| 在十个样本中搜索多个阈值 | 只允许一个外部预注册分支 |
| 交互不显著就证明加性 | 区分低功效与可辨别的无增益 |
