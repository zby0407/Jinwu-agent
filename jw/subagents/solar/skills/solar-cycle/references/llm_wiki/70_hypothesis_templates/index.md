# Module 70 — Hypothesis Templates

## Purpose

Turn the design document's mechanism directions into reusable, falsifiable
hypothesis structures rather than free-form plausible stories.

## Initial template families

1. Polar precursor: precursor state near minimum → following-cycle amplitude.
2. Waldmeier constraint: rise behavior ↔ cycle amplitude.
3. Proxy drift: indicator relationship changes by cycle, phase, or activity
   regime.
4. Cycle-length state: morphology of one cycle carries information about
   dynamo state or the following cycle.
5. Hemispheric asymmetry: north–south mismatch reflects stochastic,
   cross-equatorial, or non-axisymmetric processes.
6. Active-region/flaring context: event-rate or active-region property changes
   are secondary manifestations requiring an explicit link to the cycle-scale
   question.

## Required hypothesis-card fields

- one-sentence claim;
- physical motivation;
- observations required;
- experiment required;
- supporting result pattern;
- falsifying or weakening result pattern;
- alternative explanations and confounders;
- valid range;
- uncertainty;
- next discriminating test;
- cited Wiki entry ids.

## Boundaries

- A template is not evidence that its claim is true.
- A hypothesis without a weakening condition is incomplete.
- Prediction language must be weaker than the available evidence.

The seeded `kb_hypothesis_template_polar_precursor_001` page provides the first
example.
