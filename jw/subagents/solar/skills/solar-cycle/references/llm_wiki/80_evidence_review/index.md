# Module 80 — Evidence Review and Self-Correction

## Purpose

Provide the canonical critical rules used to score hypotheses, expose
counterevidence, adjust confidence, and prevent overstatement.

## Review dimensions from the system design

- Data support.
- Model or experiment consistency.
- Physical plausibility.
- Counterexample pressure.
- Uncertainty.
- Testability.
- Wording risk.

## Required review controls

- Separate data observation, derived statistic, model result, and mechanism
  interpretation.
- Check source coverage, calibration, sample size, and proxy status.
- Require historical-cycle stability or describe cycle dependence.
- Inspect feature ablations and dependence on a single proxy.
- Search for counterexamples and null results.
- Check that the stated valid range matches the evidence.
- Replace deterministic forecast language with bounded trend language when
  warranted.
- Trigger a conflict record when a new result contradicts canonical knowledge.

## Confidence downgrade triggers

- few polar-field cycles;
- unstable historical backtest;
- dependence on F10.7 or another single proxy;
- relationship drift;
- missing falsification condition;
- knowledge source deprecation;
- result outside an entry's valid range;
- wording that resembles an official forecast or mechanism proof.

## Required outcome

Every review ends with one of:

- bounded support;
- weakened but retained hypothesis;
- unresolved conflict;
- rejected interpretation;
- additional data or experiment required.

The outcome must include cited Wiki ids and the next discriminating test.
