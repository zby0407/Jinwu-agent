# Core Mechanism and Evidence Map

This map gives the shared causal vocabulary for the project. An arrow means a
mechanism or research dependency that must be checked against its own entry; it
does not imply that every link has equal evidential strength.

## Solar-cycle mechanism backbone

```text
solar internal flows and convection
  ├─ differential rotation
  │    └─ poloidal-field shearing
  │         └─ toroidal-field generation
  │              └─ magnetic-flux emergence
  │                   └─ bipolar active regions and sunspots
  └─ meridional flow + turbulent transport
       └─ dispersal of tilted active-region flux
            └─ polar-field reversal and rebuilding
                 └─ poloidal seed near cycle minimum
                      └─ constraint on the following cycle
```

The Babcock–Leighton framework connects these links, but prediction also depends
on uncertain transport, stochastic emergence, tilt distributions, hemispheric
coupling, and limited polar-field observations.

## Observable and proxy map

```text
sunspot number
  → empirical photospheric activity proxy
  → cycle phase, amplitude, morphology
  ≠ internal magnetic-field measurement

F10.7 radio flux
  → chromospheric/coronal activity proxy
  → useful cross-indicator comparison
  ≠ interchangeable with sunspot number under all cycles and phases

polar-field measurement or proxy
  → constraint on large-scale poloidal field near minimum
  → possible next-cycle precursor
  → short record and method-dependent uncertainty

flare occurrence and GOES class
  → active-region energy-release manifestation
  → useful secondary activity context
  ≠ long-term cycle strength or total flare energy by itself
```

## Main research hypothesis branches

1. Polar precursor: stronger polar field near minimum is associated with a
   stronger following cycle.
2. Waldmeier constraint: stronger cycles tend to rise faster, subject to
   definition and historical-cycle sensitivity.
3. Proxy drift: F10.7–sunspot relationships may vary with cycle, phase, or
   activity level.
4. Cycle-state relation: cycle length or morphology may carry information
   about dynamo state and the following cycle.
5. Hemispheric asymmetry: north–south mismatch may reflect stochastic
   emergence, cross-equatorial coupling, or non-axisymmetric components.

Each branch requires observational evidence, an experiment, a countercondition,
and a next discriminating test. None is an unconditional forecasting rule.

## Review path

```text
domain premise
  → observable or proxy
  → feature definition
  → experiment paradigm
  → result with uncertainty
  → hypothesis card
  → supporting and opposing evidence
  → confidence adjustment
  → next test or bounded conclusion
```

A valid final statement must preserve every limitation introduced along this
path.
