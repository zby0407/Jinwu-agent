# 太阳活动科研 Agent 最小研究基准测试清单

## 一、目的

这组测试不要求 Agent 直接解决“第 26 太阳活动周究竟有多强”这一完整课题，而是把目标拆成六项可以独立运行、独立判分的最小研究。六项测试分别检查：

1. 官方数据复现能力；
2. 历史关联识别与结论边界；
3. 指标关系漂移及其归因；
4. 无时间泄漏的历史回报预测；
5. 小样本条件下的证据强度判断；
6. 证据尚未成熟时是否能够暂缓预测。

每项测试只回答一个主要问题。允许得到支持、反对、证据不足或暂不可回答的结果，不以“必须得到阳性结论”为通过条件。

## 二、运行规则

- 每个测试必须在一个全新的 Agent 会话中单独运行，不向 Agent 提供本文件中的预期结果和判分说明。
- 除测试 6 外，数据截止日不影响历史结果，但仍需记录下载日期、数据版本和来源地址。
- 测试 6 的资料截止日固定为 **2026 年 6 月 30 日**。晚于该日期发布的观测或结论不得用于该次测试。
- Agent 可以自行编写和执行代码，但所有报告数值必须能追溯到实际读取的数据和实际运行的程序。
- 正式结果至少要说明：数据及版本、主要测量、方法、结果、支持证据、反对或限制证据、结论强度、下一步验证方式。
- 除非题目明确要求，不因结果不理想而增加模型、特征、显著性检验或方法套餐。
- 评测时先检查科学结论，再检查文字质量。措辞漂亮不能弥补数据口径错误、时间泄漏或过度推断。

## 三、测试总表

| 编号 | 主要能力 | 主要结论类型 | 通过要点 |
| --- | --- | --- | --- |
| SC26-B01 | 官方数据复现 | 确定性事实 | 周期 21–24 极值和上升时间正确 |

## 四、逐项测试

## SC26-B01：历史周期强度和时间尺度复现

### 给 Agent 的提示词

```text
我们先做一次最基础的历史复现。我想确认后面的分析所依赖的太阳活动周定义没有问题。

请使用 WDC-SILSO Version 2.0 的 13 个月平滑月均总太阳黑子数，整理第 21 至第 24 太阳活动周。对每个周期给出官方极小值的年月和数值、官方极大值的年月和数值，并计算从极小到极大的上升时间，单位用月。最后只根据这些量比较四个周期的强弱和上升快慢。

这一轮不要加入 F10.7、极区磁场或发电机机制，也不要自行改变太阳活动周边界。如果你从原始序列重算的极值与 SILSO 极值表不一致，请保留两者并说明原因，不要悄悄选一个。请把数据来源、版本、计算过程和最后采用的结果写清楚。
```

### 预期结果

| 周期 | 极小年月 | 极小值 | 极大年月 | 峰值 | 上升时间 |
| --- | --- | ---: | --- | ---: | ---: |
| 21 | 1976-03 | 17.8 | 1979-12 | 232.9 | 45 个月 |
| 22 | 1986-09 | 13.5 | 1989-11 | 212.5 | 38 个月 |
| 23 | 1996-08 | 11.2 | 2001-11 | 180.3 | 63 个月 |
| 24 | 2008-12 | 2.2 | 2014-04 | 116.4 | 64 个月 |

应得出的直接结论：

- 强度排序为周期 21 > 周期 22 > 周期 23 > 周期 24。
- 周期 24 是这四个周期中最弱的。
- 周期 22 上升最快，周期 24 上升最慢。
- 这些结论是历史描述，不涉及周期 26 的预测。

### 通过清单

- [ ] 明确使用 SILSO Version 2.0 和 13 个月平滑月均总太阳黑子数。
- [ ] 四个极小和极大年月与官方表一致。
- [ ] 黑子数保留到官方表提供的 0.1 精度。
- [ ] 四个上升时间分别为 45、38、63、64 个月。
- [ ] 没有把未经平滑的月均值峰值混入主表。
- [ ] 没有把描述性排序写成物理机制或未来预测。

### 关键失败

- 使用日太阳黑子数或未平滑月均值，却声称复现了官方周期峰值。
- 自行重新划分周期边界但不作说明。
- 把周期 25 的当前最大值作为已经封闭的官方周期峰值。

## SC26-B02：Waldmeier 效应的最小复现

### 给 Agent 的提示词

```text
请用一个尽量简单的历史检验看看 Waldmeier 效应在较现代的太阳活动周中是否存在。

沿用 WDC-SILSO Version 2.0 的官方周期极小和极大定义，考察第 12 至第 24 周期。把每个周期从极小到极大的月数作为上升时间，把该周期的 13 个月平滑太阳黑子数峰值作为强度。请报告样本中的 Pearson 相关系数，并逐次去掉一个周期重算相关系数，看看负相关方向是否依赖某个单独周期。

我关心的是这个历史关联的方向、大小和稳定性，不要求你证明因果关系，也不需要为了让结果更丰富而增加预测模型。请指出最不符合总体关系的周期，以及峰值定义、双峰结构或平滑方式可能给结论带来的限制。
```

### 预期结果

- 独立周期数为 13。
- 上升时间与峰值的 Pearson 相关系数约为 **-0.57**。
- 逐周期留一后的相关系数仍全部为负，约在 **-0.65 至 -0.49** 之间。
- 合理结论是：周期 12–24 支持“强周期通常上升更快”的中等负关联，方向不由某一个周期单独决定。
- 这一结果不能单独证明 Babcock–Leighton 机制，也不能直接给出周期 26 的强度。
- 周期 23 的长上升时间和较高峰值会削弱整体负相关；双峰和极值定义是实质限制。

### 通过清单

- [ ] 样本单位是 13 个太阳活动周，而不是月度观测。
- [ ] 主相关系数在 -0.58 至 -0.56 之间。
- [ ] 留一结果全部为负，且报告实际最小值和最大值。
- [ ] 使用“关联”“支持”一类措辞，没有写成确定因果定律。
- [ ] 至少指出双峰、极值定义或平滑口径中的一项限制。
- [ ] 没有把同一数据上的拟合优度冒充样本外预测能力。

### 关键失败

- 用月度数据量作为独立样本量进行显著性夸大。
- 相关方向或变量方向写反。
- 仅凭负相关宣称已经证明 11 年周期的起源机制。

## SC26-B03：F10.7 与太阳黑子数关系漂移的归因

### 给 Agent 的提示词

```text
我想检查 F10.7 与太阳黑子数之间的关系是否真的跨周期稳定，但这里要特别小心：观测或处理流程的变化也可能制造出看起来像太阳物理变化的漂移。

请使用 1947 至 2015 年的 F10.7 和 SILSO Version 2.0 太阳黑子数。先确认你选择的是哪一种 F10.7 口径，并把两个指标统一到同一时间分辨率。比较一条覆盖全时段的关系与 1980—1981 年前后分别估计的关系，检查跨时段预测残差是否存在系统偏移。同时查阅数据说明或原始研究，判断变点附近是否有观测团队、仪器或处理流程方面的记录。

最后请明确回答：现有证据更支持太阳活动指标之间的物理关系发生了变化，还是更支持 F10.7 数据生成过程存在不连续？如果两者无法完全区分，也请分别说明支持程度。不要只给相关系数。
```

### 预期结果

- Agent 应首先区分 observed、adjusted 和 absolute F10.7，不能混用。
- F10.7 与太阳黑子数总体高度相关，但时间平均会改变关系的形状，低活动水平尤其敏感。
- 应识别出 1980–1981 年附近的明显不连续。使用与既有研究一致的口径时，F10.7 相对尺度的向上跳变约为 **10.5%**。
- 变点前后可分别形成相对稳定的区间；单一全时期关系会产生系统残差。
- 结合历史元数据，更合理的主结论是：该跳变主要反映 F10.7 观测团队或数据处理过程的不连续，不能直接作为太阳物理关系漂移的证据。
- 可以保留其他缓慢物理非平稳性的可能性，但当前实验不能把它与测量不连续可靠分离。

### 通过清单

- [ ] 说明 F10.7 产品口径、单位、时间分辨率和太阳—地球距离校正。
- [ ] 太阳黑子数使用 SILSO Version 2.0。
- [ ] 识别 1980–1981 年附近的跳变，而不是只做按周期回归。
- [ ] 报告变点前、变点后各自估计，以及二者差异或跨段残差。
- [ ] 将“测量或处理不连续”列为主解释。
- [ ] 没有把所有统计漂移都自动解释成太阳发电机机制变化。

### 关键失败

- 混用 observed、adjusted、absolute F10.7。
- 将日值关系和月均关系的参数直接比较。
- 看到回归系数变化便断言太阳物理机制发生突变。
- 完全不检查观测元数据。

## SC26-B04：前一周期强度和长度的历史回报预测

### 给 Agent 的提示词

```text
我们常会说前一个太阳活动周的强度和长度包含下一个周期的信息。我想知道这个说法在真正的历史回报预测中有没有实际价值，而不只是全样本相关。

请使用 SILSO Version 2.0 的第 12 至第 24 周期。以前一周期的峰值和长度为输入，以下一周期的峰值为预测目标。只用带截距的普通线性模型，不要调参，也不要加入其他指标。对第 19 至第 24 周期逐个做按时间顺序的预测：预测某个周期时，只能使用当时已经结束的更早周期训练模型。

请同时设置一个简单基线，即使用当时训练样本中“下一周期峰值”的历史平均作为预测。对候选模型和基线都用同一批第 19 至第 24 周期计算平均绝对误差。结果中请逐周期列出真实峰值、候选预测、基线预测和两者的绝对误差，然后判断这个候选模型是否真的比基线更有预测能力。
```

### 固定计算口径

- 周期长度为相邻两个官方极小月份之间的月数。
- 目标周期 19 的训练目标为周期 13–18；之后每预测一个周期，将刚刚已经观测完成的目标加入训练集。
- 线性模型包含截距。
- 历史平均基线使用与候选模型完全相同的训练目标。
- 评价周期固定为 19–24，不随机切分。

### 预期结果

| 目标周期 | 真实峰值 | 线性模型预测 | 历史平均预测 |
| --- | ---: | ---: | ---: |
| 19 | 285.0 | 约 174.1 | 约 162.8 |
| 20 | 156.6 | 约 258.6 | 约 180.3 |
| 21 | 232.9 | 约 147.5 | 约 177.3 |
| 22 | 212.5 | 约 194.7 | 约 183.5 |
| 23 | 180.3 | 约 212.9 | 约 186.4 |
| 24 | 116.4 | 约 149.9 | 约 185.8 |

- 线性模型在六个留出周期上的 MAE 约为 **63.7**。
- 历史平均基线的 MAE 约为 **51.0**。
- 线性模型比基线差约 **12.7 个太阳黑子数单位**。
- 标准结论是：在这一固定历史回报协议下，前周期峰值和长度构成的简单线性模型没有通过预测资格审查。
- 这并不证明两个变量完全没有信息，只说明当前样本、模型和评价范围没有显示出优于简单基线的样本外能力。

### 通过清单

- [ ] 严格按时间顺序训练，没有随机切分。
- [ ] 预测目标没有进入同一折的输入或训练数据。
- [ ] 候选模型与基线使用相同的六个评价周期。
- [ ] 两个 MAE 分别接近 63.7 和 51.0。
- [ ] 明确判定候选模型未优于基线。
- [ ] 没有用训练集拟合优度推翻留出集结果。
- [ ] 没有在看到负结果后临时增加特征或改评价范围。

### 关键失败

- 使用周期 20–24 的信息训练周期 19 的预测。
- 随机拆分太阳活动周。
- 只报告候选模型误差而没有基线。
- 因为某几个周期预测方向正确就宣布模型有效。

## SC26-B05：WSO 极区磁场前兆的证据强度审计

### 给 Agent 的提示词

```text
请评估一个范围很窄的问题：Wilcox Solar Observatory 的直接极区磁场观测，在多大程度上支持“周期极小附近的极区磁场越强，下一太阳活动周越强”这一前兆关系？

请使用 WSO 公布的极区磁场序列和 SILSO Version 2.0 周期峰值。先列出能够组成的“极小期磁场—下一周期最终峰值”配对，并明确哪些目标周期已经完整结束、哪些仍未形成最终结果。主分析中把极小日前后 12 个月内南北极场绝对值的平均作为该次极小的磁场指标；如果数据缺失或 WSO 产品定义使这个口径不能直接实现，请说明并采用最接近且可复现的口径。

可以做描述性关系或逐周期回报预测，但请把一个太阳活动周作为一个独立样本，不要把月度观测数当成独立周期数。我主要想知道现有直接观测允许多强的结论，以及还缺什么证据。不要加入极区耀斑、极冠暗条或其他更长时间代理序列来扩大样本。
```

### 预期结果

- WSO 直接观测始于 1976 年左右。
- 在资料截止到 2026 年且周期 25 尚未形成官方最终峰值的条件下，主要完整配对是极小期磁场预测周期 22、23、24，共 **3 个完整独立目标周期**。
- 周期 25 可以列为正在形成或尚未封闭的目标，不能与完整历史目标同等计入最终评价。
- 直接数据通常会给出与极区磁场前兆方向相容的结果，但三个完整周期不足以支持稳定的参数估计、高置信度泛化或复杂模型。
- 标准结论应是：方向上支持或相容，但证据强度低，现有直接 WSO 样本不足以独立确认普适关系。
- 合理的下一步包括等待周期 25 结果封闭，或另设一项明确区分“直接磁场观测”和“历史代理指标”的扩展研究。

### 通过清单

- [ ] 清楚列出完整配对及其目标周期。
- [ ] 独立完整样本数识别为 3，而不是几百个月度观测。
- [ ] 周期 25 被标记为未封闭或删失目标。
- [ ] 即使相关系数很高，也明确说明三个样本下的估计极不稳定。
- [ ] 不把方向相容写成机制已证实。
- [ ] 下一步验证保持直接观测与代理指标的证据等级区别。

### 关键失败

- 把月度数据当作数百个独立预测样本。
- 在只有三个完整目标时拟合多特征模型并报告高置信度。
- 使用尚未封闭的周期 25 峰值，却不作任何状态说明。
- 偷偷加入历史代理数据后仍声称结论完全来自 WSO 直接观测。

## SC26-B06：第 26 周期正式预测的启动条件

### 给 Agent 的提示词

```text
请把资料截止在 2026 年 6 月 30 日，替我们做一次第 26 太阳活动周强度预测的“是否可以启动”评估。这次不是要求你一定给出强、中等或弱的答案，而是判断现有证据是否已经成熟到可以发布一个正式分类和可检验的峰值区间。

只考虑三类直接观测：SILSO 太阳黑子数、F10.7 射电流量和 WSO 极区磁场。请说明每类观测目前描述的是第 25 周期的当前状态，还是已经能够充当第 26 周期的前兆；同时检查第 25 周期的峰值、下降期、下一次极小和极小附近极区磁场是否已经形成可用于历史标定的同口径量。

最后请给出“可以启动”或“暂不启动”的判断，并说明最关键的缺失证据、现在最多能发布什么形式的条件判断，以及出现哪些新观测后应重新评估。不要为了让报告看起来完整而强行给出一个很窄的第 26 周期峰值区间。
```

### 预期结果

- SILSO 在截止日之前尚未给出周期 25 的完整周期终态和下一次周期极小。
- 周期 25 极小附近、用于预测周期 26 的最终极区磁场前兆尚未形成。
- 当前太阳黑子数和 F10.7 主要描述周期 25 的活动状态，不能未经历史回报验证便当作周期 26 的直接强度前兆。
- 当前 WSO 极区磁场可以用于跟踪反转后的建立过程，但不等同于已经观测到下一极小附近的最终前兆量。
- 标准判断是：**暂不启动正式的第 26 周期强／中／弱分类和窄峰值区间发布。**
- 当前可以发布：
  - 证据成熟度评估；
  - 依赖未来极区磁场强弱的条件情景；
  - 明确的更新触发条件；
  - 暂不赋予高置信度的宽范围先验。
- 重新评估至少应由以下事件触发：周期 25 进入明确下降阶段、反转后极区磁场持续建立、可在固定窗口内形成稳定前兆量，以及下一周期极小逐步可定位。

### 通过清单

- [ ] 严格遵守 2026-06-30 的资料截止日。
- [ ] 区分当前活动指标和下一周期前兆指标。
- [ ] 明确给出“暂不启动”或含义等价的判断。
- [ ] 没有编造已经观测到的周期 25 下一极小值。
- [ ] 条件情景明确依赖未来可观测量，而不是伪装成确定预测。
- [ ] 给出可执行的重新评估触发条件。

### 关键失败

- 在关键前兆尚未形成时发布高置信度窄区间。
- 把当前 F10.7 或太阳黑子数直接外推成周期 26 峰值，却没有历史回报验证。
- 把“暂不可回答”写成技术失败，而不是当前观测状态下的科学结论。
- 使用截止日之后的信息但不声明。

## 五、整体验收原则

### 最小通过条件

- SC26-B01 至 SC26-B04 必须全部通过。它们分别验证数据、关联、漂移归因和预测回报四条基础链路。
- SC26-B05 和 SC26-B06 不要求产生阳性预测，但不得出现关键失败。能正确给出“证据不足”或“暂不启动”本身就是通过。
- 任一测试出现时间泄漏、伪造执行、混淆数据产品、把月度记录冒充独立周期，或把未封闭周期写成最终事实，应直接判定该测试失败。

### 一致性复查

同一版本的 Agent 重复运行时可以有文字差异，但下列内容应稳定：

- 数据来源和周期边界；
- 主要估计量的数值或方向；
- 样本单位和样本数；
- 对阳性、阴性和证据不足结果的分类；
- 是否允许发布第 26 周期正式预测的判断。

如果 Agent 在重复运行中频繁从“未优于基线”变成“模型有效”，或从“只有三个完整周期”变成“样本充足”，说明科研判断尚不稳定。
