# H2 极区前兆假设的校正与复核

**版本：2026-08-28**  
**用途：** JW/金乌 AI Scientist 的 H2 方法改进记录与读者可见科学说明。

## 结论先行

H2 可以得到更好的物理表述和更严格的验证设计，但当前历史样本还不足以把它升级为“稳定具有预测技能”的结论。

本次校正将 H2 定义为：**太阳活动周极小期附近，两半球绝对极区场强的幅值及其不对称性，是下一活动周峰值的物理前兆**。两半球均值继续作为预先登记的主模型；较弱半球、平方根变换和按目标峰值离散度加权的线性模型作为固定的敏感性模型。敏感性模型只用于检验物理定义是否稳健，不在同一批滚动测试结果上事后挑选“冠军”。

在周期 15–24 的严格扩展窗口滚动回测中，主模型 MAE 为 **27.0**，相对逐折训练均值基线改善 **13.1** 个平滑太阳黑子数单位；固定敏感性模型的 MAE 为 25.9–26.8。可是主模型改善的 95% 配对 bootstrap 区间为 **[−7.0, 31.3]**，仍跨过零，因此 H2 的状态保持 **mixed_evidence（混合证据）**。这表示方向上有支持，但尚不能排除小样本波动。

对周期 25 的检查只作前瞻性、描述性核对：截至 2026-08-27 的暂定峰值 160.9，主模型给出 150.8，绝对误差 10.1；该点不进入历史技能门、bootstrap 区间或模型选择。

## 1. 为什么要修正 H2

旧 H2 只把一个“极区场代理均值”送入线性模型，容易掩盖两个问题：

1. 北、南半球并不总是同步，平均值可能把不对称性抹掉；
2. MWO 是经校准的孔径场代理，WSO 是磁强计观测，制度转换会改变数值尺度和误差结构。

因此，本次修正保留原主模型以保证可比性，同时把两半球原始幅值、较弱半球幅值、测量制度和峰值不确定度纳入同一份可追溯输入。这里的“加权”仅是按已登记的目标峰值离散度进行固定加权，不能解释为已经校准的预测区间。

近期研究也支持继续沿这条路线推进：数据驱动的表面通量输运重建表明，轴向偶极矩在一些设置下比半球极区通量更强；极小期极区场是下一周强度的重要前兆；极区场或偶极矩的衰减率可能提供额外的提前量。它们是方法设计的外部背景，不是 JW 本次回测的替代证据。[Pal, 2026](https://doi.org/10.3847/1538-4357/ae4c5a)；[Hathaway & Upton, 2016](https://agupubs.onlinelibrary.wiley.com/doi/10.1002/2016JA023190)；[Kumar et al., 2024](https://academic.oup.com/mnrasl/article/528/1/L27/7441123)。

## 2. 数据、时间顺序与模型

- **历史输入：** 已登记的 SILSO v2.0 平滑月总太阳黑子数、MWO–WSO 极区场表（`mwo_wso_v2`）。
- **预测起点：** 每个目标周极小期附近的 ±0.5 年窗口；窗口缺失时按既有合同使用极小期之前 1.5 年内最近观测，并保留 fallback 标记。
- **特征：** 两半球绝对场强均值 `polar_mean_abs_gauss`；较弱半球 `weakest_hemisphere_abs_gauss = min(|B_N|, |B_S|)`；峰值离散度 `target_dispersion`；MWO/WSO 制度标签。
- **滚动规则：** 前 5 个已完成周期用于初始训练，随后逐周期向前扩展；测试目标为周期 20–24，共 5 个测试点。周期 25 尚为暂定标签，不改变该技能门。
- **基线：** 每一折训练集均值和持续性（上一已观测目标峰值）。
- **不确定性：** 固定种子 20260828，10,000 次按测试折配对重采样，输出改善量的 95% 区间。

主模型为 `y = β₀ + β₁ · mean(|B_N|, |B_S|)`。敏感性模型预先固定为：

| 模型 | 物理/统计含义 | 历史 MAE |
|---|---|---:|
| 两半球均值（主模型） | 保持与已登记 H2 的可比性 | 27.0 |
| 平方根均值 | 检查强场端边际效应减弱 | 26.8 |
| 目标离散度加权 | 低离散度峰值对拟合贡献更高 | 25.9 |
| 较弱半球 | 检查“短板”是否限制下一周增长 | 26.7 |

MAE 的小幅下降是有价值的诊断，但不是凭同一测试集选择新主模型的理由。当前 `selected_challenger = null`，主模型技能门仍由原始、可比较的两半球均值模型承担。

## 3. 历史回测结果

| 指标 | 主模型 | 解释 |
|---|---:|---|
| 候选 MAE | 27.0 | 五个严格滚动测试点的平均绝对误差 |
| 训练均值基线 MAE | 40.0 | 每折只使用当时可见历史 |
| 持续性基线 MAE | 64.2 | 上一周期峰值直接外推 |
| 相对均值改善 | 13.1 | 正值表示候选更好 |
| 改善量 95% 区间 | [−7.0, 31.3] | 跨零，统计证据不足以确认稳定技能 |

逐折改善量为 20.2、−22.3、6.8、16.0、44.6；其中四折为正，一折为负。按 MWO/WSO 制度划分时，MWO 仅有一个可用于技能门的测试折，WSO 有四个。当前结果方向总体为正，但并非逐折一致；制度分层的有效样本也仍过小，不能写成跨仪器稳健性已经得到证明。

## 4. 周期 25 的前瞻性检查

使用极小期 2019-12 附近的 WSO 两半球场（北 1.02 G、南 0.71 G，均值 0.865 G），把主模型在周期 15–24 的全部已完成历史上重新拟合，得到周期 25 峰值 **150.8**。截至数据冻结日的暂定峰值为 **160.9**，误差 **10.1**；训练均值基线为 190.7，误差 29.8。

这个结果比历史均值基线更接近，但周期 25 的峰值标签仍会随 SILSO 后续观测修订。因此它只支持“当前方向值得继续跟踪”，不能回填历史测试集，也不能单独把 H2 状态改为 `skill_supported`。

## 5. 对 H2 的最终科学判断与下一步

当前最稳妥的判断是：**H2 已从单一均值代理升级为保留半球结构、测量制度和目标不确定度的物理前兆框架；历史回测显示中等幅度的描述性改善，但预测技能仍为混合证据。**

要继续“尽力为止”，下一轮应按登记协议推进，而不是继续在五个测试点上调参：

1. 登记真正的轴向偶极矩或等价球谐量，单独检验 H3/偶极矩路线；不能把普通极区孔径场改名为轴向偶极矩。
2. 扩充独立的 WSO-era 样本，并在 MWO 与 WSO 制度内分别做时间顺序验证。
3. 在新增周期标签形成后，锁定本次候选集合，再进行一次预注册的模型比较；只有在新区间不跨零、制度分层不冲突时，才考虑更换主模型。
4. 将极区场衰减率、极性反转时序等变量作为新的机制候选，先做数据可得性和泄漏审查，再进入回测。
