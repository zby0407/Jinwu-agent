# 科学假设 Agent 前端对照评分规程

## 使用规则

- 本规程与提示在查看基线答案前冻结，改进后逐项复用。
- 每项按 `0 / 1 / 2` 计分，总分 16。
- 工具调用与产物证据优先于最终自然语言自述。
- 确定性合同正确、真实模型效果与科学结论真伪是不同证据层，不互相替代。

## 八项评分

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 专家路由与闭合工具链 | 主 Agent 代写，或未形成正式产物 | 调用 `solar-hypothesis`，但工具链/保存不完整 | 子 Agent 完成 bind→evidence→validate→freeze，状态、run_id、路径一致 |
| 上游材料纪律 | 把技术失败/未核验笔记当支持或反对证据 | 能识别部分边界，但角色或缺口表达不完整 | 已完成实验、技术失败、文献来源发现三类边界全部正确 |
| 候选机制区分 | 同义改写或只有空泛单候选 | 有多个方向但区分依据较弱 | 机制、预测或观测判别上明确竞争且 pairwise distinction 成立 |
| 可证伪性 | 没有可执行的削弱/证伪条件 | 有条件但不可观测或过于笼统 | 每个候选都有可观测、方向明确且能削弱该候选的条件 |
| 下一项检验区分力 | 只建议“补数据/做更多实验” | 检验具体但不能清晰区分候选 | 目标、预期差异和被区分候选明确，能降低关键不确定性 |
| 排序可追溯性 | 无排序却声称已排序，或无理由/伪造锚点 | 有定性优先级但无七维闭合排序 | 七维 rubric、全候选覆盖、连续名次、理由与已核验证据锚点完整 |
| 不确定性与表述纪律 | 精确概率、无依据门槛或过度因果/新颖性声称 | 大体克制但证据缺口与置信理由不足 | 定性置信度与证据相称，明确缺口，不越界声称 |
| 产物完整性与一致性 | 无产物或最终自述与文件冲突 | 有产物但缺少关键路径/状态/内容一致性证据 | 正式 Markdown、结构化产物、run_id、哈希/状态及最终答复相互一致 |

## 附加观察（不计入总分）

- 合同修复轮次。
- 实际工具调用序列。
- 是否使用上游检查或排序工具；工具不存在时记录为基线能力缺口。
- provider、model、thinking（仅记录非敏感配置）。
- 运行时错误、重试与 stderr。
