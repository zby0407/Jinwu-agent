# 科学假设 Agent 前端冻结任务

> 本提示在改进前冻结；改进后必须逐字复用，不得依据基线结果调参。

请把下面任务交给 `solar-hypothesis` 科学假设子 Agent 完成，不要由主 Agent 自行代写，也不要调用数据与特征 Agent或证据审查 Agent：

读取项目中的高级请求 `@hypothesis/inputs/handoff_demo_request.json`，围绕“第24活动周极小期长于第25活动周，更可能由发电机机制变化解释，还是由观测口径差异解释？”形成可检验的竞争假设组合。

要求：

1. 区分已完成的同口径复算、技术失败的极区磁场实验与未经原文核验的文献笔记；技术失败不得当作反对证据，文献笔记不得被虚构成已核验支持。
2. 候选必须在机制或可观测预测上真正可区分，写清适用范围、必要前提、替代解释、混杂因素、可证伪条件和会削弱候选的观测。
3. 给出最有区分力的下一项检验，说明它如何区分候选，而不是泛泛建议“增加数据”。
4. 若当前工具支持，请按既定七维 rubric 给出初步排序；每个名次必须有理由与已核验证据锚点。若证据不足以强排序，应明确降低置信度，不得编造锚点。
5. 完成正式保存，并在最终答复中如实报告完成状态、`run_id` 和产物路径。

不要执行新实验，不要声称获得输入之外的新观测结果。
