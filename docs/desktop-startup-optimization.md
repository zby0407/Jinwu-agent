# 桌面后端启动优化与验证

日期：2026-10-29。基线为 PR #58 合入后的远端 main，桌面源码版本为 0.3.3。

## 改动与原因

主智能体构建存在重复子图编译。Deep Agents 0.6.12 先构建任务委派工具，再收集父任务私有状态字段并重建工具。两次构建使用相同的子智能体定义，却分别编译子图；当前默认配置共调用子图编译 22 次。

`jw/graph_build.py` 在一次主图构建内复用相同定义和状态类型对应的已编译子图，编译次数降至 11 次。上游任务工具仍按原规则重建，父任务私有字段过滤继续生效。复用范围随构建结束释放，各次构建和并发构建分别持有自己的上下文；请求指定的动态响应格式继续交由上游编译。桌面主图、复现主图和 CLI 主图共用这一入口。

`jw/utils.py` 的子智能体配置读取优先使用 PyYAML 的 `CSafeLoader`，减少长 YAML 提示词的解析开销。缺少 C 扩展的源码环境仍使用 `SafeLoader`，两条路径均拒绝 Python 对象标签。

这两项改动减少实际初始化工作量。子图在主智能体就绪前完成编译，没有新增首次任务触发的延后编译，也没有修改界面的就绪判定。

## 性能结果

在同一 WSL Ubuntu 环境、Python 3.12 和同一套依赖下比较基线与优化版。每次启动新进程、使用隔离目录和合成模型配置；构图基准禁止网络连接。两版按轮次交替先后顺序，计时期间没有并行运行测试或构建。以下使用全部样本的中位数，未启用性能剖析器。

| 测量项 | 每版样本数 | 基线 | 优化后 | 耗时下降 |
|---|---:|---:|---:|---:|
| Kimi 配置下主图构建 | 6 | 2.045 秒 | 1.821 秒 | 10.95% |
| Qwen 配置下主图构建 | 6 | 2.046 秒 | 1.908 秒 | 6.75% |
| 后端进程启动至主智能体可发送，Kimi 配置 | 4 | 2.521 秒 | 2.264 秒 | 10.17% |

独立的性能剖析确认子图实际编译次数由 22 次减少至 11 次。两种模型配置下，各轮基线与优化版的 134 个工具及模型可见参数定义完全一致。真实后端检查通过 `/api/runtime-status` 的 `canSend` 判定就绪，8 次退出后测试端口均关闭。

## 功能与交付检查

两组相关自动测试合计 **235 项通过**：

- 92 项覆盖构图、子智能体配置、任务能力、MCP、异步子智能体、技能范围、CLI 加载、桌面运行状态和复现入口。
- 143 项覆盖流事件、模型切换和观测记忆调用路径。

新增测试执行了本地假模型驱动的真实 LangGraph：首次主任务、同步与异步子任务均成功；首次执行没有增加子图编译。父任务已有的大额模型调用计数不会泄漏到子任务。另覆盖并发构建、不同模型隔离、构建失败后再次构建、动态响应格式和 YAML 对象标签拒绝。

受影响 Python 文件的 Ruff 检查、格式检查和补丁空白检查通过。Python wheel 构建成功，新增构图模块进入发行包。测试输出保留一项 Starlette/httpx 弃用提示，以及模型切换测试中的一项未等待协程警告。

## 复现与证据

源码构图基准入口：`scripts/benchmark_agent_startup.py`。准备与优化版独立的基线源码目录后，在相同 Python 环境执行：

```bash
python scripts/benchmark_agent_startup.py \
  --source /path/to/candidate \
  --baseline /path/to/baseline \
  --output /path/to/results \
  --samples 6 --provider moonshot
```

将 `--provider` 改为 `dashscope` 可重复 Qwen 配置测试；`--profile` 仅用于定位函数耗时和调用次数，剖析结果不混入上述常规计时。

本次原始计时、工具接口、剖析数据、后端测试脚本、测试日志和 wheel 位于本地 `workspace/startup_optimization_20261029/`，总表为该目录的 `summary.json`。生成的模型配置仅含合成凭据，测试结束即清理隔离目录。

## 边界与后续

- 以上是当前 WSL 源码环境的工程验证，不能直接作为 Windows 安装包的启动成绩，也不属于清空操作系统文件缓存后的冷启动测试。个别采样有波动，结果表示本次各组中位耗时的变化。
- 本轮没有执行真实服务商请求或完整科研实验；首次任务行为使用本地假模型验证。
- 子图复用通过 Deep Agents 的 `create_sub_agent` 构建函数接入，适用于当前锁定的 0.6.12 版本。升级该依赖时应重跑构图、私有状态、动态响应格式和并发测试。
- 尚未重新制作或安装 Windows/macOS 桌面安装包。下一步在 Windows 打包环境集成本改动，使用同一机器和配置复测主智能体就绪与首次任务，并完成安装、升级和退出验收后发布。
