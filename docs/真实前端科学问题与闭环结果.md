## 本轮代码调整

### Qwen 流式传输异常

r12 在 Hypothesis 阶段出现远端提前关闭流，主图随后收到 `APIConnectionError`。为使该
类偶发传输错误得到一次有界恢复，同时不掩盖领域或参数错误，作了两处调整：

1. `jw/middleware/qwen_compat.py` 识别 Qwen 传输异常，并对同一异步请求最多重试一次；
   非 Qwen 请求、领域校验错误和 API 参数错误不重试，第二次传输失败继续显式抛出。
2. `jw/llm/models.py` 将 Qwen/DashScope SDK 默认 `max_retries` 设为 0；如果环境显式
   设置该值，仍按环境值覆盖。这样总重试次数由中间件统一控制，避免 SDK 与中间件叠加。

本调整不改变模型提示词、研究问题、数据值或科学判定规则。

### r15–r19 的数据编排与后续 Data Agent 增强

r15–r19 的早期调整没有修改 `jw/subagents/solar/solar_data.yaml`，也没有把新的数据源或观测值
写回 Data Agent。早期修改集中在下游：编排层把已接受的逐周期表转换为相邻周期配对表，自动
实验模块和 Schema 负责传递、执行、记录及校验同一实验输入。后续质量改进已修改 Data Agent，
增加任务绑定的学术检索、网页来源获取、小型数据分析、v2 周期表和结构化回执；这些增强不增加
观测值，也不预写科学结论。样本单位、时间信息集、测量制度差异和事后标签等限制继续随产物进入
后续审查。完整文件清单见
[`Data_Agent与数据编排调整说明_2026-08-16.md`](Data_Agent与数据编排调整说明_2026-08-16.md)。

### 科学结果

当前十个相邻周期对不能判定“上一周期较长会削弱极区场前兆效率”，也不能判定相反方向成立：

- 交互系数 `β3=12.0217`，周期对重抽样区间为 `[-71.2719, 106.2204]`，覆盖零；
- 五项预注册支持条件通过数为 0；
- 加性零模型置换尾部比例为 `0.5193`，未提供反对加性模型的证据；
- 交互模型滚动原点 `MAE/RMSE=81.27/117.63`，高于加性模型的 `34.06/43.44`，也未优于持续性和
  均值基线；
- 剔除 23→24 对或采用极小日期最长情景会使交互方向翻转；
- 真实滚动原点只有五个可估折，有效独立样本量仅有上界 10，功效和最小可检测交互幅度尚未量化。

最终科学状态为高不确定性、低功效。主交互假设保留为可复验的正式估计问题；加性模型维持工作模型
地位，但“未拒绝”不等于零效应已经证明；MWO/WSO 测量体制差异继续作为竞争解释。结论只适用于
周期 15–24 的十个相邻周期对和本次无符号极区场估计量，不包含因果机制、发电机体制、原创性或显著性
声明，也不发布周期 25 或任何未来周期的正式预报。
