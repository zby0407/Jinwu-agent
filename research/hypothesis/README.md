# 科学假设 Agent 1.0

科学假设 Agent 1.0 在 Pi 中接收自然语言研究问题，基于用户提供的上游材料（研究规划、文献笔记、真实实验结果）形成、审查、比较与更新科学假设，并把候选组合整理为 Markdown 假设组合。它不执行实验，不把合理猜测包装成已有发现，也不为凑数生成同义改写。

## 快速使用

在 PowerShell 中进入项目目录并启动 Pi：

```powershell
Set-Location "E:\2026tzb\dist\科学假设agent"
pi
```

Pi 使用 `dashscope/qwen3.7-max-2026-06-08` 和 `high` 推理等级。首次使用可先检查运行环境：

```text
/scientific-hypothesis-doctor
```

在命令列表中选中 `/scientific-hypothesis` 后直接回车，Pi 会弹出输入框，不会因为命令后没有文字而提交空任务。普通用户直接描述要解释的问题即可：

```text
/scientific-hypothesis 太阳活动周24与25极小期长度差异可能由哪些机制解释？
```

也可以随问题给出自动实验 Agent 的 run 目录，Agent 会先核验其哈希与科学终态，再把已核验结果作为证据：

```text
/scientific-hypothesis 结合 E:/2026tzb/dist/自动实验agent/runs/<run_id> 中已核验的复算结果，判断第24周极小期延长更可能是发电机机制还是观测口径差异。
```

也可以用 `inputs/` 中的高级 JSON 请求精确声明上游材料、已有假设版本或候选上限：

```text
/scientific-hypothesis @inputs/example_request.json
```

## 运行控制

```text
/scientific-hypothesis-status
```

查看当前请求绑定、已登记证据数量和检查进度。任务中断后再次输入 `/scientific-hypothesis` 会从保留的进度继续，不要求重新提交问题。

## 科学边界

- 已有发现不是假设；机制不是可观测预测；观测相关不等于因果解释。
- 实验证据只来自含原始指标的真实执行记录；技术失败的实验记录、日志和元数据不能当作科学证据，只能记为证据缺口。
- 上游自动实验产物必须先通过哈希与科学终态核验（仅 `completed_*` 终态）；未通过核验的产物一律阻断，只列为证据缺口，绝不降级为猜测。
- 空结果用于更新假设，不自动证伪全部候选；证据冲突时保留竞争候选。
- 置信度只写较高、中等、较低及理由，不写精确概率；没有检索核对证据时不得声称“首次提出”。
- 可泛化表述超出数据覆盖范围（如 JW-FD 磁图只覆盖 2011 年前后个别活动区）的候选，置信度不得为较高。
- 证伪条件和检验信号中的数值门槛必须能追溯到已绑定证据或用户原话。
- 每个候选必须把研究对象、时间/阶段、空间、数据口径、方法口径、成立条件、失效条件和外推限制分开写；边界条件不能用“适用于……”一句话代替。
- 每个候选明确标注主张是探索性还是受证据约束、机制是证据推断还是探索性推断、实证支持是已核验/部分/无；Wiki 机制条目不能冒充实证支持。
- 每个候选必须说明不确定性来源、对结论的影响以及降低不确定性的具体办法。
- 没有已绑定实证支持时不得写“所有/普遍/任何活动周”等无界泛化；“显著/明显/稳定”等词若没有预注册判据、误差界/区间和检验方法，不构成可证伪条件。

## 输出文件

每次运行保存在 `runs/<run_id>/`：

- `hypotheses.md`：面向研究者的假设组合。含初步排序（每条名次附理由与关键证据锚点）、按候选组织的主张/结构化边界条件/认识论状态/机制/预测/支持与反对证据/证据缺口/替代解释/混杂因素/可证伪条件/不确定性/下一项检验，以及独立的反例与冲突点一节。
- `hypothesis_portfolio.json`：结构化机器记录，含证据登记簿、排序、反例/冲突点区块和组合哈希。
- `hypothesis_request.json`：绑定时的标准请求。

排序是本 Agent 的初步初审（rubric 七维：数据支持度、模型一致性、物理合理性、不确定性、反例周期、消融敏感性、漂移风险），下游证据审查 Agent 会独立复审。报告只使用自然科研语言；内部字段、检查轮次、证据 id 和保存机制不出现在正文中。历史运行不会被覆盖或修改。

系统由六个 Pi Tools 和八个可组合 Skills 构成，公共合同使用 `scientific-hypothesis-*-v1`。详细架构见 [科学假设Agent技术说明.md](科学假设Agent技术说明.md)，测试与日常操作见 [科学假设Agent测试与使用手册.md](科学假设Agent测试与使用手册.md)。
