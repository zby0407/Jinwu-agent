# 三个科研 Agent：研究背景与设计说明

本项目对应挑战杯揭榜挂帅 XH-202619 阿里云榜题中“太阳活动周起源探秘”方向。我们没有把任务理解成让大模型直接给出一个太阳活动周 26 数字，而是把它拆成一个可以被证据反驳的科研闭环：当前数据能约束什么、哪些机制仍然竞争、什么实验最能区分它们。

## 研究问题

主问题是：**太阳活动周 25 后期观测，能否对活动周 26 的强度趋势与物理机制形成有边界、可复核、可反驳的约束？**

需要交付的不是“模型很聪明”的叙述，而是：趋势或区间、支持证据、反证、不确定性、混杂因素和下一项最小判别实验。

## 科学背景

太阳黑子数大约以 11 年为一个活动周期；磁极性完整恢复约需 22 年，即 Hale 磁周期。Babcock–Leighton 类图景把倾斜双极活动区、磁通输运、极区场反转和下一周期环向场联系起来，但观测代理、稀疏前兆样本与低阶模型都不足以单独证明完整发电机机制。

本项目把证据分成四层：

- 太阳黑子总量与活动周形态：用于分段、Waldmeier 稳健性和基线。
- F10.7 与黑子数：用于检查代理关系是否随周期和相位漂移。
- 南北半球活动：区分 1992 年前重建层与之后直接观测层，并在重叠期校准。
- WSO 极区场：检查极区先兆，但完整“极小期—下一周期峰值”配对很少，结论保持探索性。

## 三条研究路线

1. **活动周 26 的有界约束**：输出趋势等级或区间，以及置信度为何下降；不冒充官方预报。
2. **竞争机制**：检查 11/22 年周期、极区反转与低阶 Babcock–Leighton 解释链，同时保留替代机制。
3. **代理与半球漂移**：用跨周期、分相位和半球校准判断经验关系是否稳定，并用负对照击穿偶然相关。

E0–E8 分别承担数据版本、分段基线、Waldmeier 留一周期、F10.7 分相位漂移、扩展半球校准、极区先兆稳健性、低阶模型族消融、负对照/安慰剂和洁净复现检查。它们不是同一个脚本换名字。

## 三个 Agent 如何分工

| Agent | 负责 | 不负责 |
|---|---|---|
| Research Planner | 主张边界、证据地图、数据可行性、预注册 DAG、指标/预算/停止规则 | 运行实验、看结果后改计划 |
| Experiment | 预检、因果切分、注册实验、多 seed、负结果、失败诊断、不可变谱系 | 任意写代码、挑阳性 seed |
| Hypothesis | 竞争假设、定量预测、反证、近邻去重、双顺序复核、最小判别实验 | 用模型意见或排名代替证据 |

四个人工复核点不能自动跨过：冻结计划前、接受高风险数据/假设前、把统计关联升级为机制表述前、对外发布结论前。

## 借鉴的 AI for Science 设计

| 来源 | 本项目吸收的做法 | 没有照搬的部分 |
|---|---|---|
| [AI Co-Scientist, Nature 2026](https://www.nature.com/articles/s41586-026-10644-y) | 假设生成、反思、成对复核、演化与 meta-review | 不把模型排序当科学真值 |
| [Robin, Nature 2026](https://www.nature.com/articles/s41586-026-10652-y) / [代码](https://github.com/Future-House/robin) | 多阶段、可追踪的研究迭代 | 不声称端到端自治等于发现成立 |
| [PaperQA2](https://arxiv.org/abs/2409.13740) / [代码](https://github.com/Future-House/paper-qa) | 检索、证据摘取与引用接地 | 新文献先进入待核验区，不能直接 claim |
| [ToolUniverse](https://github.com/mims-harvard/ToolUniverse) | 紧凑入口背后的可发现工具注册表 | 禁止任意 Shell、任意 URL 和未审查工具 |
| [OpenScholar](https://www.nature.com/articles/s41586-025-10072-4) / [代码](https://github.com/AkariAsai/OpenScholar) | 证据检索与引用约束 | 本地证据账本仍是主张真源 |
| [AstaBench](https://openreview.net/forum?id=M7TNf5J26u) 与 [ScienceAgentBench](https://openreview.net/forum?id=6z4YKr0GK6) | 用真实任务、工具轨迹和失败边界评测 Agent | 不以单次流畅回答作为能力证明 |
| [AI Scientist-v2](https://arxiv.org/abs/2504.08066) | 预注册、实验迭代与可复现产物的架构启发 | 仓库是定制 Responsible AI License，本项目未复制其受限代码 |

这也是为什么 Pi 表面只显示五个科研元工具，而后台有 17 个角色隔离能力：Agent 先发现和检查工具，再执行并验真，既丰富能力，又让评审能看清每一步的输入、哈希和主张边界。角色由父进程绑定，模型不能自行切换；验真依赖 Pi 父进程 HMAC 认证的 hash-only 收据，不接受自造结果或普通哈希自签。该边界防的是受限模型子进程越权，不替代操作系统沙箱。

## 最终边界

- NOAA 对当前周期的产品不是活动周 26 官方预报。
- 相关性、代理量、低阶模型和 Elo/成对排序都不能证明太阳周期起源。
- `warning` 要降置信度；`inconclusive`、`failed`、`quarantined` 不能作为支持证据。
- 当前三 Agent 默认路由为固定快照 `dashscope/qwen3.7-max-2026-06-08`；正式 Qwen/百炼结论仍必须有真实调用、无 fallback 的独立证明，任何迁移前旧模型的历史开发验证都不能替代。
